Manual de uso

1

Configure a API (1x só)

Clique no ⚙ no topo da extensão. Na aba Providers, cole pelo menos uma API key:

  • Claude (recomendado): console.anthropic.com/settings/keys
  • OpenAI: platform.openai.com/api-keys
  • Gemini (mais barato): aistudio.google.com/app/apikey

Clique em Testar conexão, depois Salvar chaves.

2

Gere a transcrição no Premiere

No Premiere Pro:

  1. Importe o vídeo no Project panel
  2. Menu Window → Text (abre o painel Text)
  3. Na aba Transcript, clique em Transcrever sequência
  4. Escolha o idioma e clique Transcrever
  5. Aguarde o processamento (1-3 min)
3

Exporte a transcrição

Ainda no painel Transcript do Premiere:

  1. Clique no ícone ⋯ (três pontos) no canto do painel
  2. Escolha Exportar transcrição
  3. Selecione Texto (.txt) ou JSON (.json)
  4. Salve em qualquer pasta (ex: Desktop)
💡 Dica: Qualquer formato funciona. A FASTVIDEO detecta automaticamente. TXT puro do Premiere é o mais simples.
4

Use a extensão

  1. Passo 1: Escolha o vídeo no dropdown (lista todos os clipes do projeto) ou clique "Usar o selecionado no Premiere"
  2. Passo 2: Arraste o arquivo TXT/JSON/SRT exportado do Premiere na área de transcrição (ou clique para selecionar do computador)
  3. Passo 3: Escreva seu briefing
  4. Passo 4: Configure modo, duração, quantidade (marque Máximo pra IA extrair o quanto conseguir)
  5. Clique Iniciar extração
  6. Revise os trechos, marque/desmarque, e clique Adicionar à timeline
  7. Se quiser recomeçar do zero, use o botão 🔄 Limpar tudo no final
✨ Regra da timeline: tudo entra em UMA ÚNICA timeline.
• Modo contínuo: cada trecho extraído ganha uma cor de rótulo diferente, com 30s de gap entre trechos.
• Modo compilação: cada variação é um GRUPO com a mesma cor (se a variação tem 3 trechos, os 3 ficam com a mesma cor). Grupos diferentes = cores diferentes. Gap de 30s entre grupos.
• No final, o vídeo original completo é adicionado com gap de 90s (pode desativar).
5

Salve seus briefings favoritos

Depois de escrever um bom briefing, clique em 💾 Salvar, dê um nome (ex: "Pegada emocional"). Da próxima vez, use 📂 Carregar.

Três templates já vêm prontos:

  • Pegada emocional
  • Financeiro / Empresarial
  • Reels educacionais

⚠ Problemas comuns

"Transcrição vazia ou inválida": O arquivo pode estar corrompido. Re-exporte do Premiere como TXT.
"Sem sequência ativa": Marque "Criar nova sequência" antes de inserir na timeline.
"API error" ao extrair: Teste a conexão nas Settings. Verifique crédito no provider.
Cortes cortam no meio da frase: Use Sonnet 4.6 ou Opus 4.7 para maior precisão (especialmente modo compilação).

  • Modos: trecho contínuo ou compilação multi-cut
  • Timeline: insere subclipes não-destrutivos
