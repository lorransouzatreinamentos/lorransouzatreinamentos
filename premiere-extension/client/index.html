Manual de uso

1

Configure as APIs (1x só)

Clique no ⚙ no topo da extensão. Na aba Providers, cole as keys necessárias:

  • OpenAI (obrigatório para transcrição Whisper): platform.openai.com/api-keys
  • Claude (recomendado para análise): console.anthropic.com/settings/keys
  • Gemini (mais barato): aistudio.google.com/app/apikey

Clique em Testar conexão, depois Salvar chaves.

💡 OpenAI é usada para transcrever o áudio (Whisper). Você ainda pode escolher qualquer provider (Claude/OpenAI/Gemini) para a análise dos cortes.
2

(Opcional) Instale FFmpeg

Vídeos maiores que 24MB precisam de FFmpeg para extrair o áudio. Também é recomendado para vídeos menores — reduz custo e tempo de transcrição em até 4x.

  • macOS: brew install ffmpeg
  • Linux: sudo apt install ffmpeg
  • Windows: baixe em ffmpeg.org e adicione ao PATH
Sem FFmpeg instalado? Ainda funciona para vídeos < 24MB (o arquivo é enviado direto).
3

Arraste o vídeo e analise

  1. Passo 1: Arraste o arquivo de vídeo na área grande (ou clique para abrir o seletor do sistema). A extensão reconhece .mp4, .mov, .mkv, .webm, etc.
  2. Passo 2: Escreva um briefing claro (o que você quer extrair desse vídeo).
  3. Passo 3: Mantenha a fonte de transcrição em Transcrever com IA (padrão recomendado). A alternativa manual está no mesmo bloco, só se você já tem o TXT/SRT.
  4. Passo 4: Escolha o modo:
    • Extrair falas inteiras: um trecho contínuo por corte. Ideal para palestra, aula, podcast.
    • Criar vídeos com cortes: monta vídeos costurando falas de momentos diferentes (hook + body + payoff).
  5. Clique Analisar vídeo. A extensão transcreve o áudio com Whisper, gera candidatos, envia para IA e lista as sugestões.
📁 A transcrição fica em cache local (por hash do arquivo). Se você refizer a análise com outro briefing, não transcreve de novo.
🔄 Botão Reprocessar transcrição força uma nova chamada ao Whisper (ignorando o cache).
4

Revise, refine e insira

  1. Cada card traz score, duração, headline, hook, caption e texto completo.
  2. Use os botões por card para iterar sem refazer tudo:
    • ✨ Melhorar: pede uma versão melhor do mesmo trecho.
    • 🎣 Novo gancho: troca só a abertura (hook).
    • 🔀 Variação: uma ideia parecida em outro momento.
    • 🗑 Descartar: remove o card.
  3. Marque os checkboxes dos que quer usar e clique Adicionar à timeline. Se o vídeo ainda não está no Project, a extensão importa automaticamente.
✨ Regra da timeline: • Extrair falas: cada fala vira um vídeo separado com cor própria, gap de 30s.
• Criar vídeos com cortes: cada vídeo é um grupo de cortes com a mesma cor; grupos diferentes = cores diferentes; gap de 30s entre grupos.
• Cortes são inseridos apenas uma vez (dedup no cliente E no host).
5

Salve seus briefings favoritos

Depois de escrever um bom briefing, clique em 💾 Salvar e dê um nome (ex: "Pegada emocional"). Da próxima vez, use 📂 Carregar.

Três templates já vêm prontos: Pegada emocional · Financeiro/Empresarial · Reels educacionais.

⚠ Problemas comuns

"Drag-drop não forneceu caminho local": Clique no dropzone em vez de arrastar — abre o seletor nativo do CEP que sempre retorna o path.
"FFmpeg não encontrado" (vídeo >= 24MB): Instale com brew install ffmpeg (Mac) ou use a opção avançada "Importar transcrição manual".
"Sem sequência ativa": Marque "Criar nova sequência" antes de inserir na timeline.
"API error" durante análise: Teste a conexão nas Settings. Verifique crédito no provider.
Cortes cortam no meio da frase: A IA recebe candidatos pré-validados — raramente acontece. Se acontecer, use "Melhorar este corte" no card.

FASTVIDEO

Extensão para Adobe Premiere Pro que extrai os melhores trechos de vídeos usando IA.

  • Transcrição: automática via OpenAI Whisper (ou manual como fallback)
  • Providers análise: Claude, OpenAI, Gemini
  • Modos: extrair falas inteiras ou criar vídeos com cortes
  • Cache: transcrição salva em ~/.fastvideo-cache por hash do arquivo
  • Timeline: subclipes não-destrutivos, sem duplicação
